# Parity rows, MY: Multi yard platform

The detail behind the [MY rows of the parity matrix](../LBM-PARITY-MATRIX.md#my-multi-yard-platform). R, B and A refs link the Rundoo, BisTrack and Agility pages each claim rests on; Gable's evidence links its code on `refactor/v1` at `58dde7e8`.

## MY-01

**Branch level security (users and roles held to branches).** Priority **MUST**: Multi yard security on by default for a multi yard dealer, grants managed on screen.

- **Rundoo** (Yes, documented): 47 per person permissions in seven sections plus manager PIN or login key gates; staff access is location scoped while owners see every store. Multi yard: A clerk granted one location does not see another's inventory or sales; a separate permission allows switching the signed in location. [R21](https://www.rundocs.com/help/admin-settings/permissions/) [R20](https://www.rundocs.com/help/admin-settings/locations/) [R12](https://rundoo.ai/product/run-on-a-stable-secure-private-platform/) [R23](https://www.rundocs.com/help/admin-settings/pos-security/) [R22](https://www.rundocs.com/help/admin-settings/staff/)
- **BisTrack** (Partial, documented): User permissions are grouped and can differ between WMS enabled and other branches; BisTrack Web user profiles control menus; Epicor Identity adds single sign on and two factor. Holding users to specific branches is not described. Multi yard: Permissions vary by branch type, not documented per branch. [B69](https://www.mydoitbest.com/wp-content/uploads/2024/02/Whats-New-in-BisTrack-2023.2.pdf) [B30](https://www.epicor.com/en-us/products/enterprise-resource-planning-erp/bistrack/bistrack-web-and-epicor-identity/) [B33](https://www.epicor.com/en-us/blog/technology-and-data/introducing-bistrack-web/)
- **Agility** (Yes, documented): Organization security assigns roles per branch by position in an org hierarchy (branch, region, company); action and data allocations limit cross branch views such as A/R for all branches. Multi yard: Core multi yard security. [A119](https://documentation.dmsi.com/Agility/prod/System_Administration/organizationsecurity.htm) [A27](https://restdoc.dmsi.com/) [A120](https://documentation.dmsi.com/Agility/prod/System_Administration/securitydataallocation.htm)
- **Gable today** (Partial): Users granted branches with a home branch; middleware checks X-Branch-Id against the grants (admin and owner may omit it); payload and path id branch guards; branch bound machine keys pinned; desk branch switcher and branch users screens. **Missing:** The wall is off until multi_branch_enabled is set (installed false); roles are global, not per branch; reports, GL and bank are not walled; users sending no header are not yet held to grants everywhere. **Open work:** PR 119: a user with no branch in context is held to its grants on POS, orders, POs, AP, quotes, customers, CRM, accounts, exposure, reporting and the dashboard.. Evidence: [`core/pkg/middleware/branch.go:205`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/core/pkg/middleware/branch.go#L205), [`core/pkg/middleware/branch.go:166`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/core/pkg/middleware/branch.go#L166), [`core/migrations/059_default_branch_setting.sql:45`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/core/migrations/059_default_branch_setting.sql#L45), [`core/migrations/061_user_locations.sql:9`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/core/migrations/061_user_locations.sql#L9), [`core/pkg/middleware/keybranch.go:42`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/core/pkg/middleware/keybranch.go#L42), [`core/internal/app/serve/wire_branch_wall_test.go:367`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/core/internal/app/serve/wire_branch_wall_test.go#L367), [`web/apps/desk/src/pages/admin/branches/BranchUsers.ts:18`](https://github.com/FutureBuildAIinc/gable/blob/58dde7e851596e735cab81b08f576b950323f0cc/web/apps/desk/src/pages/admin/branches/BranchUsers.ts#L18).
