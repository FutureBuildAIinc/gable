# Parity rows, IN: Inventory across branches

The detail behind the [IN rows of the parity matrix](../LBM-PARITY-MATRIX.md#in-inventory-across-branches). R, B and A refs link the Rundoo, BisTrack and Agility pages each claim rests on; Gable's evidence links its code on `refactor/v1` at `695d587c`.

## IN-01

**On hand by branch or yard and by bin or location.** Priority **MUST**: On hand by yard and bin is the base of multi yard stock.

- **Rundoo** (Yes, documented): Per location row for each product with bin, on hand, on order, committed, min and max; bin prints on labels and pick lists. Multi yard: On hand and bin held per location; product list defaults to the current location. [R52](https://www.rundocs.com/help/inventory/products/) [R8](https://rundoo.ai/product/manage-pricing-purchasing/) [R2](https://rundoo.ai/industries/lumber/)
- **BisTrack** (Yes, documented): Real time stock levels across locations; stock on hand by branch and category; bin locations for picking, labels and stock checks. Multi yard: Quantity by location inside a branch needs Epicor WMS Foundations or Enterprise, which is enabled branch by branch. Add on or partner: Epicor WMS for location based item tracking. [B4](https://www.epicor.com/en-us/products/enterprise-resource-planning-erp/bistrack/order-management-tools/) [B7](https://www.epicor.com/en-us/products/enterprise-resource-planning-erp/bistrack/bistrack-financial-management-tools/) [B2](https://www.epicor.com/en-us/products/enterprise-resource-planning-erp/bistrack/ptw-mobile-warehouse-applications/) [B27](https://assets.epicor.com/m/37c597a01d93eb79/original/Epicor-BisTrack-Yard-Warehouse-Management-Options-Flyer.pdf) [B69](https://www.mydoitbest.com/wp-content/uploads/2024/02/Whats-New-in-BisTrack-2023.2.pdf)
- **Agility** (Yes, documented): On hand and available by branch; locations and sublocations with default and permanent locations per item; lot and tag tracking. Multi yard: Branch inventory lists return quantities for every branch. [A84](https://documentation.dmsi.com/Agility/prod/Data_Files/locations.htm) [A27](https://restdoc.dmsi.com/)
- **The MVP** (Partial, master): Stock rows per (product_id, location_id) and branch location tree (location/handler.go:57); AdjustStock (inventory/service.go:21) accepts nil location; GET /api/v1/inventory (handler.go:70, repository.go:95) has no branch wall; Locations.ts is an unrouted flat list.
- **Gable today** (Partial): Inventory rows sit at a branch root, zone, or bin; levels and yardstock sum a yard's tree, counter sales and returns deduct and restock at the register's branch, and Desk Stock tab reloads on yard switch. **Missing:** Unique index allows one branchless row per product; ReceivePO without location_id writes a branchless row; order fulfillment deducts only the order branch's root row (`location_id IS NULL`), stranding stock received into bins. Evidence: [`core/internal/inventory/levels.go:19`](https://github.com/FutureBuildAIinc/gable/blob/695d587c5d7431194005a93bec51deb53c3e2749/core/internal/inventory/levels.go#L19), [`core/internal/inventory/qty.go:50`](https://github.com/FutureBuildAIinc/gable/blob/695d587c5d7431194005a93bec51deb53c3e2749/core/internal/inventory/qty.go#L50), [`core/internal/inventory/qty.go:224`](https://github.com/FutureBuildAIinc/gable/blob/695d587c5d7431194005a93bec51deb53c3e2749/core/internal/inventory/qty.go#L224), [`core/internal/inventory/repository.go:54`](https://github.com/FutureBuildAIinc/gable/blob/695d587c5d7431194005a93bec51deb53c3e2749/core/internal/inventory/repository.go#L54), [`web/apps/desk/src/pages/inventory/tabs/ProductStockTab.ts:15`](https://github.com/FutureBuildAIinc/gable/blob/695d587c5d7431194005a93bec51deb53c3e2749/web/apps/desk/src/pages/inventory/tabs/ProductStockTab.ts#L15). ## IN-02
